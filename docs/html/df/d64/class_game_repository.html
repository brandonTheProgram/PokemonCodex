Detailed Description

An extension of the Repository class for Pokemon Games.

This class manages the database for anything related to Pokemon Attacks: Pokemon Games (Sword, Shield, Scarlet, Violet, etc) Pokemon Mainelines Games (Sword & Shield, Legends: Arceus, etc)
